# 🟡 Pac-Man Game 🎮

A classic Pac-Man game built using **HTML, CSS, and JavaScript (Canvas API)**.  
Control Pac-Man, eat all the food, and avoid ghosts to survive!

---

## 🚀 Features

- 🎮 Smooth Pac-Man movement using keyboard
- 👻 Multiple ghosts with random movement
- 🍔 Food collection system with scoring
- ❤️ Lives system
- 🔁 Game restart functionality
- 🧠 Collision detection (walls, ghosts, food)

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Canvas API)
